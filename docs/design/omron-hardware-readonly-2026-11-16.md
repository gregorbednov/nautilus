## Найденное и исправленное поведение конечного блока

Исходный `ReadProgram` запрашивал до992 bytes и ожидал короткий конечный блок.
Реальные CPU отвергают запрос, пересекающий конец области, кодом1104. Начальные
блоки успешны: на CJ1M отказ получен с offset11904/count992, на CJ1H —
offset1984/count992. Минимальное чтение четырёх байтов от нуля успешно, но не
содержит конечного флага и потому не выдаётся CLI за полную резервную копию.

Исправление относится только к0306: при1104 уменьшать размер запроса с
выравниванием на4, сохраняя смещение, вплоть до4. Уменьшенный размер сохраняется
для оставшихся чтений. Ошибку1104 не считать EOF: обязателен конечный флаг.
На минимальном размере ошибка возвращается вызывающему коду. Иные ошибки CPU,
тайм-аут, повреждённые ответы и команды записи повторно не выполняются.

Тесты покрывают размеры4/196/1200/2048/2880/12288/12380, границу области,
отсутствующий конечный флаг и отсутствие повторов других отказов. После
исправления получены четыре полные копии UM; ранние успешные payload-блоки
также совпадают с префиксами полных файлов. Оба файла приняты существующим
N1-инспектором, включая FB-секции и полные длины.

## Что это ещё не подтверждает

- Состав живых UM отличается от эталонных проектов с одним определением,
  двумя экземплярами и двумя задачами. Соответствие актуальным CXP из projects
  не установлено; старые эталоны нельзя считать текущей программой установки.
- Первые служебные слова живых образов ненулевые, в отличие от прежних файлов
  библиотечного компилятора. Их назначение и правила передачи не установлены;
  нельзя обнулять, удалять или нормализовать их для записи по предположению.
- Version в identity содержит несколько значений с внутренними NUL. Точная
  unit version и ёмкости CPU не считаются расшифрованными.
- Копии содержат программу UM, не полную резервную копию I/O memory,
  сохраняемого состояния, PLC settings, I/O table или файлов карты памяти.
- Запись, соответствие генерируемого N1 wire-передаче, инициализация,
  восстановление и исполнение новых программ не проверены. Общий
  `hardwareQualified` остаётся false.

Следующие работы без изменения установки: сопоставление с актуальными
сохранёнными CXP, анализ служебных полей, расширение компилятора на проекты
без FB и остальные фактически встреченные формы. Любые проверки записи —
только на отдельно разрешённом изолированном стенде.

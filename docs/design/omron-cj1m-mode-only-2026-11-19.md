# CJ1M: подтверждённый mode-only опыт на настоящем CPU

19 ноября 2026 года. Пользователь явно подтвердил ранее отклонённый опыт:
«Разрешаю этот опыт на CJ1M». Это разрешение относится к обычному получению
права, PROGRAM→RUN прежней программы и явному освобождению права без записи UM;
при ошибке остановка, с возможной необходимостью ручного действия.
Прежняя подготовка/отказ сохранены без изменений в
[отчёте controlled session](omron-cj1-controlled-session.md).

## Выполнение

Использован точно тот же проверенный Go драйвер CJ1M и backend `de7e6a54`.
На10.0.174.36:9600, CJ1M_CPU21,19 ноября02:02:22–02:02:30 UTC
(05:02:22–05:02:30 МСК) выполнены:

1. Проверка полного rawCPU по сохранённому capture, исходного RUN4 и отсутствия
   fatal/nonfatal; затем две свежие совпадающие копии программы в RUN.
2. Обычный0C01, STOP0402, чтение PROGRAM0.
3. Проверка неизменности исходного UM, явный0401/RUN, чтение RUN4.
4. Явный0C03 и последующее чтение статуса.
5. Новое соединение только для чтения CPU/status/UM после завершения сессии.

Журнал содержит ровно четыре control-attempt и четыре соответствующих ACK:
`0C01 → 0402 → 0401(mode04) → 0C03`. Статусы подтверждают4→0→4.
Итоговый RUN4, fatal=0, nonFatal=0; полные rawCPU158 bytes и rawstatus
совпали с исходными. RELEASE ACK сохранён, session.finished=true.
Он не является постоянной гарантией отсутствия другого владельца.

## Программа и область доказательства

**До управляющих команд** получены две одинаковые копии UM по4672 bytes.
Это уже другой снимок, чем4652 bytes от18 ноября. Изменение возникло до опыта;
источник изменения не установлен. Свежий backup и последующее отдельное чтение
после mode-cycle совпали во всех байтах, включая service words:

`a4c0b45ba391fcd0cefb49bce52058168971e4aca1e6b29fe05937f80961c8cf`.

Go ReviewProgramBackup прошёл. В журнале нет0307 write-attempt, attemptedBlocks
кандидата и возврата равны0. Кандидат2624 bytes локально пересобран для контракта
сессии, но не отправлялся. ProgramBytesReconciled=false: передачи/возврата UM
не было. Vendor runtime, forced acquire, очистка ошибок и снятие защиты не вызывались.
HardwareQualified/WriteQualified/RestoreQualified/FullControllerBackup=false.

Теперь mode-only путь независимого backend наблюдён на обоих настоящих CPU:
CJ1H —2716 bytes без изменений; CJ1M —4672 bytes без изменений в ходе опыта.
Полная загрузка N1, защита/выбор0307 или0317, профиль/финализация, backup вне UM
и аппаратный возврат исходника остаются отдельными незавершёнными проверками.
Обрыв с полученным правом и автоматическое восстановление не квалифицированы.
Production CLI остаётся читающим; этот опыт выполнен отдельным исследовательским
Go драйвером. Код backend не менялся, поэтому полный тестовый набор не повторялся:
проверены фактический журнал, обе backup copies, новое чтение и Go backup review.

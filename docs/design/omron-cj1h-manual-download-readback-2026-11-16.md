# CJ1H: чтение после ручной загрузки CXP

**Исторический снимок.** После последующего занятия новый опрос выявил другую
2716-byte программу. Это не отменяет описанного ниже совпадения в прежний
момент, но оно больше не описывает текущую программу. См.
[новую инвентаризацию](omron-cj1h-new4-inventory-2026-11-16.md).

16 ноября 2026 года, после первоначального чтения и offline-сверки.
Оператор сообщил о ручной загрузке CXP через CX-One на CJ1H10.0.174.37,
выбрав **все доступные сегменты**. Во время передачи было предупреждение
`failed to download data`; полный текст, отказавший сегмент и этап неизвестны.
Это сообщение оператора, не захваченный агентом лог передачи.

Разрешение агенту остаётся **только чтение действующей установки**. После
ручной загрузки агент использовал лишь FINS/TCP0501 identity,0601 status и
0306 program read; не писал программу/данные, не менял режим и не повторял
штатную передачу. CJ1M в этой сессии не опрашивался.

## Подтверждено чтением

- Endpoint: `10.0.174.37:9600`, CPU из ответа `CJ1H_CPU65H`.
- До и после: status5, mode4, fatal0, nonFatal0; сырые ответы сохранены.
- Два полных UM по4604 bytes совпадают, SHA-256
  `3d4c2e0781600e0219dcef9713aa6a4fcdc33d750b1a85140382ad5e3f901cf3`.
- Прежний2880-byte UM имел SHA-256
  `efba98dbd8a2c54e277b00ff4834f1cb5caf8953fae33f2bce3374a2f85c4512`.
  Новая программа отличается от него; старые результаты остаются историческим
  снимком, а не описанием текущего CJ1H.
- Новый UM: BLINK definition0/body1024, два экземпляра, задачи256
  `MotorDrive_LIFT_1` и257 `NewProgram1`. Task records: offsets784/975,
  lengths191/176, code154/139 words. Directory offset496.

## Независимая компиляция и полное сравнение

Локально, без CX-One, тот же CLI скомпилировал неизменённый CJ1H CXP из projects:

- source SHA-256:
  `4a1c46b3b36696a0f957759d7087ff7f562d154f08ea0d33c5dbbac53fdb236c`;
- профиль CJ1H-H CPU65, BCD, явные настройки из
  `omron/compiler/testdata/n1-example-settings.json`;
- settings SHA-256:
  `89cab0772baa06b03e2f812d9a64e31dfb4f4cb97a6ea5ca88e22d7257fea9c5`;
- независимый файл4604 bytes, SHA-256:
  `05c6fede7156d53eaafb2173726c8af26f7963cee2a4cd54d1d1ceb2f35ef4bf`.

Сравнены **все байты**, без обнуления, удаления или нормализации неизвестных полей.
Различаются только три32-bit слова, индексы от нуля:

| Word offset | Считанный UM | Независимый N1 |
| --- | --- | --- |
| 0 | 000029a8 | 00000000 |
| 1 | 0000a2be | 00000000 |
| 4 | 00000048 | 00000000 |

Все остальные1148 из1151 слов совпадают. В частности, полностью совпадают
тела и обёртки обеих задач, определение/экземпляры FB, task configuration,
directory и остальные поля заголовка. Назначение трёх служебных слов пока
не установлено: называть их checksum, игнорировать для записи или вычислять
по предположению нельзя. Полные файлы **не побайтно идентичны**.

Это первое подтверждение, что независимая сборка данного неизменённого CXP
воспроизводит код и разобранные структуры программы, фактически прочитанной
с этого CJ1H после операторской загрузки. Проверка не ограничена сходством
состава/имён. Она не доказывает универсальную компиляцию всех CJ1-проектов.

## Предупреждение пока не объяснено

Чтение подтверждает наличие совпадающей программы UM, но не успешность всех
выбранных сегментов передачи. В этой сессии не проверялись PLC Settings,
I/O table, symbols/comments, I/O memory, сохраняемые значения, карта памяти
и прочие доступные оператору сегменты. Какие из них реально были в диалоге,
не зафиксировано. Нулевые fatal/nonFatal не заменяют проверку этих сегментов.

Не выполнены независимая запись, проверка начальных данных, корректности
исполнения/физических выходов и восстановление. `hardwareQualified` и
`writeQualified` остаются false; совпадение прочитанного кода имеет отдельный
подтверждённый результат. Стек AC0 здесь является явным входом компилятора;
автоматическое происхождение настройки из сохранённого CXP ещё не доказано.

Следующие шаги: уточнить полный warning/transfer log и отказавший сегмент,
установить значения служебных полей и проверить необходимые настройки
отдельными разрешёнными чтениями. На действующей установке не повторять
загрузку, не инициализировать данные и не менять режим для диагностики.
